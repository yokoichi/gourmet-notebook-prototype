# グルメ手帳 — 静的プロトタイプ

スマホ・PCで操作感を確かめる、GitHub Pages向けの試作です。最初の店舗と配布ファイルはすべて架空の合成サンプルです。

- 店舗一覧、店名/住所/メモ/タグの検索、ジャンル絞り込み、手動追加/編集。
- URLを1店舗10件まで追加・削除。http/httpsだけを検証し、保存時の自動アクセスはしません。「開く」は保存済みで変更していないURLだけ、本人のクリックで別タブへ移ります。
- 項目設定で追加・編集フォームの表示名・順序・表示/非表示・必須/任意を変更。店名は表示・必須。文字列のカスタム項目を20件まで追加できます。非表示や改名で値を消しません。一覧や検索の表示は設定に連動しません。
- 編集では変更した項目だけを反映し、未変更のタグ・内部改行を保持します。タグ内の区切りや改行は引用符で囲めます（例：`"朝,昼", 夜`）。タグ内の引用符は2つ重ねます。タグは12個、各30文字までです。
- UTF-8 CSV/JSONのブラウザ内解析とプレビュー。CSVは2 MiB・1,000候補、JSONは8 MiB・2,000店舗まで。全状態も2,000店舗かつ店舗＋設定JSONで8 MiBまでです。内容量によって先に容量上限に達します。
- 引用符・カンマ・改行のあるCSV、Saved相当の列名、店舗配列/版付き独自JSONに対応。全Takeout形式、Maps JSON/GeoJSON、ZIPは未対応。
- 全項目＋設定JSONのローカル書き出し・確認付き復元、合成分類例、チケット計算の見積例。

入力・取り込み・項目設定はメモリ内だけで扱い、再読み込みで合成8店舗と標準設定に戻ります。必要ならJSONを書き出し、実際に保存できたことを確認してください。認証・端末同期・サーバ保存・実AI・購入・チケット消費は未実装です。選択ファイル・解析結果は送信しません。ページ資源の取得通信とGitHub側のアクセス記録は別です。外部フォント/CDN/分析タグ、ブラウザ永続ストア、Service Workerを使いません。

CSVはname/title/店名の列が必須です。address、phone、genre、tags、memo/note、mapsURL/item_content_url/urlは任意です。項目の表示名を変更しても、この列対応は変わりません。旧店舗配列と`{"schemaVersion":1,"restaurants":[...]}`も読み込み、単一mapsURLをURL配列に移します。電話は文字列で指定してください。旧形式の未対応項目はプレビューで警告します。

## 店舗＋設定のバックアップ

書出しは`schemaVersion:2`、`format:"gourmet-notebook-prototype"`、`fieldSettings`、`restaurants`を持つJSONです。店舗のname/genre/phone/address/tags/memo/urls/customValuesと設定を含みます。カスタム項目のIDは表示名と独立し、改名しても値を保持します。旧版アプリはv2を復元できません。この改修版で使ってください。JSONの例はexamples/backup-v2-sample.json、旧v1の例もexamples/に残しています。

- 「店舗を追加する」が初期選択です。完全一致の重複候補は初期値スキップ、共通URLや同名住所だけなら注意候補として追加できます。既存店舗は上書きしません。不正行は追加できません。
- 「読み込んだ表示・必須設定も適用」は初期値OFF。必要な新custom定義は非表示・任意で追加して値を保持します。ONでも現在だけにあるcustom定義と値は残します。
- 設定のプレビューでは項目IDごとに現在・ファイル・反映後の表示名、順序、表示、必須を比較できます。OFFなら現在の設定を維持する項目、復元なら置換後に含まれない定義も表示します。
- v2だけ「店舗と設定を置き換えて復元する」を選べます。現在の件数と設定を置換する説明を読み、必要なら現在のJSONを書き出し、確認チェック後に確定してください。復元は全件・全設定で、同一内容の店舗も除外しません。0件のバックアップも復元可能です。
- 手動保存では設定した必須項目を検査します。取込み・復元は店名以外の必須未入力を警告し、古い内容を復元不能にしません。

カスタム値は1,000文字、表示名40文字、URLは各2,000文字まで（UTF-16コード単位）。状態確定と書出しに同じUTF-8 JSON容量判定を使うため、この版で書き出した有効なバックアップは2,000件・8 MiBの範囲で置換復元できます。入力内容や設定は容量超過で部分反映せず、エラーを表示します。原本ファイルは変更しません。

開発資料、分析プロンプト、実データ、秘密はこの公開repoに含めません。分析プロンプトはローカルで検討し、承認後にサービスへ反映します。

## ローカル確認

依存パッケージは不要です。Node.js 20以降で`npm test`。表示はこのフォルダで`python3 -m http.server 8765 --bind 127.0.0.1`を実行し、`http://127.0.0.1:8765/`を開きます。

GitHub Pagesはmainのルートを静的配信します。公開予定のURLは`https://yokoichi.github.io/gourmet-notebook-prototype/`です。購入や実アカウントの機能がある本番版ではありません。
